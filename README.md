# سیاره کوچولو

پیش‌نمایش فارسی و راست‌به‌چپ فروشگاه مریم، مناسب موبایل و دسکتاپ.

## ویرایش سایت

فایل `index.html` را در گیت‌هاب باز کنید، دکمهٔ مداد را بزنید و پس از تغییر، **Commit changes** را انتخاب کنید. GitHub Pages تغییرات شاخهٔ `main` از پوشهٔ ریشه را منتشر می‌کند؛ انتشار ممکن است چند دقیقه طول بکشد.

فهرست ۱۲ محصول و قیمت‌های نمونه در بخش `const products` همین فایل است. رنگ‌ها و ظاهر در بخش `<style>` قرار دارند. سایت هیچ وابستگی خارجی یا مرحلهٔ ساخت ندارد.

## امکانات آزمایشی

فیلتر سن و دسته‌بندی، انتخاب دنیای فضایی و دایناسوری، جست‌وجو و افزودن و حذف از سبد خرید. سبد با بازخوانی صفحه خالی می‌شود. پرداخت، سفارش و دانلود واقعی فعال نیستند.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید.
